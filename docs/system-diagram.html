② Two Main Workflows
Path A — SEO Audit
/seo audit <url>
Full parallel audit. 14 agents fire simultaneously. Each writes one raw .md file. Takes 3–8 minutes per site.
Phase 0: Brainstorm Phase 1: Plan Phase 2: 14 Parallel Agents Phase 3: Review + Score Phase 4: Fix Plan Phase 5: Reports
OR
Path B — Content Pipeline
/blog brand init → /seo write-blog <keyword>
Generates SEO-optimized blog articles from audit findings. 5 specialist agents collaborate. 5-gate quality contract enforced.
Brand init Research Write Review (100pt) SEO check Render HTML+PDF
